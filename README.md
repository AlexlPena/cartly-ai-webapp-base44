# Cartly AI

Cartly AI is a smart grocery shopping assistant that helps users organize grocery lists, generate meal ideas using AI, and track food expiration dates to reduce waste.

The application combines list management with AI-powered suggestions to simplify grocery planning and everyday meal preparation.

---

## Overview

Planning groceries and meals can be frustrating and disorganized. Many people rely on scattered notes, forget ingredients, or allow food to expire before it gets used.

Cartly AI solves this by combining:

- AI-powered grocery list generation
- Meal idea suggestions
- Grocery list management
- Food expiration tracking

All in a single web application.

---

## Problem

Many people struggle with:

- Forgetting ingredients when shopping
- Not knowing what meals to cook during the week
- Letting food expire before it gets used
- Managing grocery lists across multiple apps or notes

These issues lead to wasted time, wasted food, and unnecessary spending.

---

## Solution

Cartly AI provides an organized platform where users can manage grocery lists while receiving AI assistance for meal planning and list creation.

The AI assistant can generate meal ideas, build shopping lists, and help users stay organized while planning their groceries.

---

## Key Features

### AI Grocery List Generation
Users can prompt the AI to generate grocery lists based on meal ideas or weekly meal plans.

### Meal Suggestions
The AI assistant provides meal ideas and ingredient recommendations.

### Grocery List Management
Create, edit, and organize multiple grocery lists in one place.

### Expiration Date Tracking
Users can track expiration dates of food items to help reduce waste.

### Simple and Clean Interface
Designed to make grocery planning fast and easy.

---

## Example Workflow

1. User asks the AI for meal ideas or grocery suggestions  
2. The AI generates meals and ingredient lists  
3. The grocery list is automatically saved  
4. Users track food expiration dates for items they already own

## Running the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/cartly-ai.git
```

### 2. Navigate to the project directory

```bash
cd cartly-ai
```

### 3. Install dependencies

```bash
npm install
```

### 4. Create a `.env.local` file and add the required environment variables

```env
VITE_BASE44_APP_ID=your_app_id
VITE_BASE44_APP_BASE_URL=your_backend_url
```

### 5. Start the development server

```bash
npm run dev
```
